# DTWAVE

Персональный сайт Дмитрия Терещенко и его системы персонального здоровья **WAVE**.

Статический одностраничный сайт: HTML5 / CSS3 / vanilla JS, без сборки и зависимостей.

## Структура проекта

```
dtwave/
├── index.html      # вся разметка и контент сайта
├── style.css       # стили
├── script.js       # интерактивность (меню, аккордеон, форма, анимации)
└── images/         # фотографии автора (оптимизированы для веба)
```

## Локальный просмотр

Открыть `index.html` в браузере напрямую, либо поднять локальный сервер:

```bash
python3 -m http.server 8080
# затем открыть http://localhost:8080
```

## Деплой

Сайт полностью статический — подходит любой статический хостинг:

- **GitHub Pages**: Settings → Pages → Deploy from branch → `main` / `root`
- Netlify / Vercel: подключить репозиторий, build command не нужен, publish directory — корень репозитория
- Любой обычный хостинг: залить содержимое папки по FTP/SFTP

## Перед публикацией — обязательно заполнить

В `index.html` есть плейсхолдеры, которые нужно заменить на реальные данные:

- [ ] Ссылки на WhatsApp (`wa.me/...`) и Telegram (`t.me/...`)
- [ ] Ссылки на Instagram, YouTube, VK
- [ ] Ссылка на тренировочное приложение
- [ ] Email в форме заявки (сейчас `mailto:` заглушка) — для автоматической обработки заявок рекомендуется подключить Formspree, Telegram-бота или CRM
- [ ] Реальные отзывы клиентов (сейчас 3 карточки-заглушки в разделе «Результаты»)
- [ ] Цены в разделе «Форматы и стоимость» (сейчас «по запросу»)
- [ ] `sitemap.xml`, `robots.txt` и код аналитики (Яндекс.Метрика / Google Analytics) — при подключении домена

## Технические заметки

- Изображения оптимизированы и лежат в `images/` (JPEG, сжаты под веб)
- Основной цвет — тёмная ржавая охра `#B23A1A`, палитра — оттенки серого/чёрного
- Шрифты подключены через Google Fonts: Oswald, Inter, IBM Plex Mono
- Фирменный элемент — «дыхательная линия» под шапкой сайта, одновременно индикатор прокрутки страницы
